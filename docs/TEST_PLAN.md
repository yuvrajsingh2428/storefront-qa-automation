# Test Plan

## Scope
End-to-End UI validation of the static storefront application.

## Test Suites
1. **Smoke Suite**: Critical business flows (P0).
2. **Sanity Suite**: Targeted functional checks (P1).
3. **Regression Suite**: Exhaustive coverage of all features (P2).

## Risk-Based Testing
- P0: Checkout, Cart, Add to Cart, Totals
- P1: Discount, Quantity update, Remove Item, Navigation
- P2: Formatting, Display, Gift Message, Edge cases
