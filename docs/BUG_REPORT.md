# Bug Severity & Priority Guidelines

## Severity
- **Critical**: System crash, total blocker (e.g., Checkout broken).
- **High**: Major feature broken with no workaround.
- **Medium**: Minor feature broken, or workaround exists.
- **Low**: Cosmetic, formatting, spelling issues.

## Priority
- **P0**: Fix immediately.
- **P1**: Fix in current sprint.
- **P2**: Fix in next sprint.
- **P3**: Backlog.
